# dji-thermal-ui-docs

The documentation of [dji-thermal-ui](https://github.com/WinuxNomacs/dji-thermal-ui), the Thermal Analyzer, as
GitHub Pages serves it: https://winuxnomacs.github.io/dji-thermal-ui-docs/

This repository holds the built site only. Its sources are the app's `docs/` folder, built with Zensical; the app
also serves the same documentation offline from its header's Help. Don't edit the pages here: each commit replaces
them with a new build, made by the app's `scripts/publish_docs.py`, which keeps only this README and the licence.

licence, which the built site carries.
